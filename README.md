# CV Website

A personal portfolio website built with Gatsby, React, and TypeScript,
featuring a modern design powered by Tailwind CSS.

## Tech Stack

- **Framework**: [Gatsby](https://www.gatsbyjs.com/)
- **UI Library**: [React](https://reactjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Component Documentation**: [Storybook](https://storybook.js.org/)
- **Content**: [MDX](https://mdxjs.com/)

## Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [pnpm](https://pnpm.io/)

## Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/shorodilov/shorodilov.github.io.git cv-website
   cd cv-website
   ```

2. **Install dependencies:**

   ```bash
   pnpm install
   ```
