# CV Website

A personal portfolio website built with Gatsby, React, and TypeScript,
featuring a modern design powered by Tailwind CSS.

## Tech Stack

- **Framework**: [Gatsby](https://www.gatsbyjs.com/)
- **UI Library**: [React](https://reactjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Component Documentation**: [Storybook](https://storybook.js.org/)
- **Content**: [MDX](https://mdxjs.com/)

## Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [pnpm](https://pnpm.io/)

## Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/shorodilov/shorodilov.github.io.git cv-website
   cd cv-website
   ```

2. **Install dependencies:**

   ```bash
   pnpm install
   ```

## Project Structure

- `src/pages/` - Gatsby page components.
- `src/styles/global.css` - global stylesheet entry point.
- `src/images/` - image assets, including the Gatsby manifest icon.
- `.storybook/` - Storybook configuration.
- `.ai/rules/` - repository-specific AI assistant rules.
- `gatsby-config.ts` - Gatsby site metadata and plugin configuration.
- `package.json` - package metadata and script entry points.
- `prettier.config.ts` - Prettier formatting configuration.
- `postcss.config.ts` - PostCSS and Tailwind CSS pipeline configuration.
