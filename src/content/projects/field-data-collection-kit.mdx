An all-in-one field kit and supporting server platform for spatial data
collection teams working on navigation projects in the EU and USA. The field
system handled GPS data, provided route points to collection teams, and streamed
collection progress to managers.

Onboard software worked with server-side data aggregation and distribution,
coverage analysis, and a project-management dashboard. Communication between
field kits and server services was secured with JWT.

## Responsibilities

- Designed electrical schematics and firmware to automate field data handling.
- Developed onboard services for the field kit.
- Developed server-side data aggregation and distribution services.
- Contributed to coverage analysis and project-management dashboard functionality.
- Created detailed documentation for individual parts of the ecosystem.
