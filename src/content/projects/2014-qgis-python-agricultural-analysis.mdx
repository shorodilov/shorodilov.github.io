I developed a separate set of QGIS plugins for another
customer. Their functional scope matched the earlier C++ extensions, but the
implementation used Python bindings for the same QGIS, Qt, and GEOS ecosystem.

The plugins analyzed data from the QGIS canvas, performed spatial clustering of
measured indicators, generated heatmaps for chemical elements from soil
samples, and produced PDF reports according to customer requirements. The
customer defined how analytical clusters should be interpreted as problem
areas.

## Responsibilities

- Developed Python-based QGIS extensions for a separate customer.
- Implemented the same spatial clustering workflows as the C++ toolset.
- Generated soil-sample heatmaps and customer-specific PDF reports.
- Worked with the Python bindings for QGIS, Qt, and GEOS functionality.
