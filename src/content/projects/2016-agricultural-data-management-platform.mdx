An agricultural customer moved from multiple QGIS workstations and
local Shapefile/GeoJSON workflows to a centralized web service. Existing
analytical functionality from the earlier QGIS plugins was migrated into the
new platform, while PostgreSQL/PostGIS became the central spatial data store.

The web application exposed an interactive Leaflet map and retained the spatial
clustering, heatmap, and reporting capabilities developed for the desktop
workflow. Heavy spatial operations ran as background jobs through Celery and
Redis, while WebSockets pushed notifications and job-status updates to the
frontend in real time. Authentication used JWT.

I worked primarily on the backend using Flask, psycopg2, SQLAlchemy, Alembic,
GDAL, and GEOS, while also preparing and configuring the geospatial parts of the
frontend.

## Responsibilities

- Developed the Flask backend and centralized spatial-data workflows.
- Worked with PostgreSQL/PostGIS through psycopg2 and SQLAlchemy.
- Managed schema evolution with Alembic.
- Implemented background spatial processing with Celery and Redis.
- Integrated WebSocket updates for real-time status and notifications.
- Configured the Leaflet-based geospatial frontend functionality.
