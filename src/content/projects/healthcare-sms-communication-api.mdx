In 2022, I contributed to an event-driven communication service for a healthcare
platform. The service focused on SMS processing and integrations with external
SMS providers.

The backend used Python and Flask, while service communication relied on gRPC,
HTTP/2, and Protocol Buffers. The wider technical stack also included Docker and
Apache Beam, with one- and bidirectional streaming used for communication flows.

The engagement was relatively short, so I no longer retain detailed knowledge
of each provider-specific workflow. The portfolio description therefore keeps
those integrations intentionally at a high level.

## Responsibilities

- Developed integrations with external SMS providers.
- Implemented backend flows around provider-facing communication.
- Contributed to gRPC-based service communication and streaming workflows.
- Worked within the platform's event-driven communication architecture.
