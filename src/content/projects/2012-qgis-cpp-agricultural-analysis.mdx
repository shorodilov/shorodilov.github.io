I developed a series of QGIS extensions for an agricultural
customer. The plugins worked with data from the QGIS canvas and generated PDF
reports according to customer-defined requirements.

The analytical functionality included spatial clustering of measured indicators
and heatmaps of chemical elements derived from soil samples. The customer
defined how resulting clusters should be interpreted as problem areas.

The implementation used C++, the QGIS API, Qt, and the GEOS API.

## Responsibilities

- Developed C++ extensions against the QGIS and Qt APIs.
- Implemented spatial clustering and visualization workflows.
- Built heatmaps from soil-sample measurements.
- Used GEOS for geometry-related operations.
- Generated customer-specific spatial reports in PDF form.
