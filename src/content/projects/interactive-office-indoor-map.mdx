This internal side project was built by a small group of enthusiasts between
2012 and 2014, with a second version developed around 2017. Its original goal
was simple: help colleagues find one another in a large office when work
required face-to-face collaboration at a specific desk.

The first version used map tiles and a map-server setup. I configured the map
server, wrote JavaScript for workstation popups, and worked on map styling.
Employee information was stored in PostgreSQL.

The second version moved the map to SVG and stored the map data, including SVG
content, in PostgreSQL. It added room search for facilities such as kitchens and
gyms, plus integration with Microsoft services in the Azure ecosystem to show
meeting-room availability and create bookings. The exact Microsoft API used is
no longer confirmed.

The v2 backend used Flask, SQLAlchemy, and Alembic, while the frontend used
React and Redux.

## Responsibilities

- Configured the map-server side and workstation popups for the first version.
- Worked on map and interface styling.
- Contributed to the architectural redesign of the second version.
- Developed the Flask backend and PostgreSQL-backed data model for v2.
- Helped integrate room discovery and meeting-room availability workflows.
